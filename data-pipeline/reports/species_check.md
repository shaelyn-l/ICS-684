## Guild values (bird count file)

From the Biocomplexity metadata. Only the bird count file has a guild column.

| guild | meaning |
|---|---|
| NA | No data recorded |
| ENDM | Native birds – Native bird species, i.e. Hawaiian endemic passerines and indigenous species |
| XNTV | Non-native birds - Non-Phasianidae introduced bird species |
| GAME | Gamebirds – Game birds, i.e. bird species within the Phasianidae family, all introduced |

Rows with guild `NA` (pandas reads this as missing unless told otherwise): REJU ×4, NOBI ×1. REJU has no other guild value; see its row in the lookup. NOBI is not a species.

## Guild vs. native

`native` is true where the guild is ENDM and false for XNTV and GAME. Codes merged into one species share the native status of the code that has a guild. MODO and AFSI appear only in the blood file, so their native status is from outside knowledge (both introduced). REJU's comes from the GAME guild definition.

No disagreements between `count_guild` and `native`.

## Other notes

- `NOBI` ("No birds detected") is not a species. It marks a counting event with zero detections, so it matters for birds-per-count denominators in Step 1.5.
- Honeycreeper status is outside knowledge: the metadata doesn't classify species beyond the guild.
- Hawaiian common names are written with ʻokina and kahakō; the metadata omits them.
